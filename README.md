# 📚 Tentang Project

LMS (Learning Management System) ini dibuat menggunakan framework Laravel dan digunakan untuk:

- Manajemen course
- Login multi-user
- Dashboard admin & student
- Sistem pembelajaran online
- Upload materi
- Monitoring data siswa

---

# 🚀 Teknologi yang Digunakan

- PHP
- Laravel
- MySQL
- Blade Template
- Bootstrap / Tailwind
- JavaScript
